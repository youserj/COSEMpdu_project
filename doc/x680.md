# X.680 — Base ASN.1 Types

## Overview

The `x680` module contains definitions of all base ASN.1 types according to the X.680 standard (Abstract Syntax Notation One). It is the foundation upon which all BER (X.690) and A-XDR (IEC 61334-6) encoders/decoders are built.

The module provides:
- **`Type` Protocol** — base interface for all ASN.1 types.
- **Simple types** (`Simple`, `BuiltinType`) — `INTEGER`, `BOOLEAN`, `NULL`, `OCTET STRING`, `BIT STRING`, `ENUMERATED`, string types.
- **Structured types** — `SEQUENCE`, `SEQUENCE OF`, `CHOICE`.
- **Helper classes** — `NamedType`, `NamedValue`, `Tag`, `Class`, constraints (`ConstraintSpec`, `ValueRange`, `SizeConstraint`).

## Module Contents

### Base Protocol

| Class | Purpose |
|-------|---------|
| `Type` | Base protocol for all ASN.1 types. Defines `default()`, `__eq__()` methods. |
| `Simple[T]` | Simple type with a native value `value: T`. Inherits `Type`. |
| `BuiltinType` | Marker protocol for built-in ASN.1 types (§16.2). |
| `ReferencedType` | Marker protocol for referenced types (§16.3). |

### Simple Types (Simple)

| Class | ASN.1 Type | Native Representation | Tag (UNIVERSAL) |
|-------|------------|----------------------|-----------------|
| `BooleanType` | BOOLEAN | `int` (0/1) | 1 |
| `IntegerType` | INTEGER | `int` | 2 |
| `BitStringType` | BIT STRING | `tuple[int, ...]` | 3 |
| `OctetStringType` | OCTET STRING | `bytes` | 4 |
| `NullType` | NULL | `None` | 5 |
| `ObjectIdentifierType` | OBJECT IDENTIFIER | `tuple[int, ...]` | 6 |
| `EnumeratedType` | ENUMERATED | `int` | 10 |

### String Types (CharacterString)

| Class | Purpose |
|-------|---------|
| `RestrictedCharacterStringType` | Base class for restricted string types. Value: `str`. |
| `GraphicString` | GRAPHIC STRING |
| `VisibleString` | VisibleString |
| `Utf8String` | UTF8String |
| `GeneralizedTime` | GeneralizedTime |

### Structured Types

| Class | Purpose |
|-------|---------|
| `SequenceType` | SEQUENCE — ordered set of named components. Components defined via `components: ClassVar[tuple[NamedType, ...]]`. |
| `SequenceOfType[T]` | SEQUENCE OF — homogeneous list of elements of type `T`. Value: `list[T]`. |
| `ChoiceType` | CHOICE — selection from alternative types. Alternatives defined via `alternatives: dict[int, Type]`. |

### Named Components

| Class | Purpose |
|-------|---------|
| `NamedType[T]` | Required SEQUENCE component: `(identifier: str, type_: type[T])`. |
| `OptionalNamedType[T]` | OPTIONAL component. May be absent in encoding. Inherits `NamedType`. |
| `DefaultNamedType[T]` | DEFAULT component with a default value. Inherits `NamedType`. |
| `NamedValue` | Named value (for INTEGER, ENUMERATED, BIT STRING): `(identifier: str, value: int)`. |

### Helper Types

| Class/Alias | Description |
|-------------|-------------|
| `Tag` | ASN.1 tag: `(class_number: int, class_: Class)`. |
| `Class` | Tag class (IntEnum): `UNIVERSAL`, `APPLICATION`, `CONTEXT_SPECIFIC`, `PRIVATE`. |
| `UniversalClassTagAssignments` | Universal tag number table (ISO/IEC 8824-1:2021 Table 1). |
| `Members` | Protocol for types with named values (`members: ClassVar[tuple[NamedValue, ...]]`). |
| `InitError` | Exception on type initialization error. |
| `INTEGER` | `type INTEGER = int` |
| `BIT_STRING` | `type BIT_STRING = tuple[int, ...]` |
| `BOOLEAN` | `type BOOLEAN = int` |
| `NULL` | `type NULL = None` |
| `OCTET_STRING` | `type OCTET_STRING = bytes` |
| `OBJECT_IDENTIFIER` | `type OBJECT_IDENTIFIER = tuple[int, ...]` |
| `STRING` | `type STRING = str` |
| `SEQUENCE_OF[U]` | `type SEQUENCE_OF[U] = list[U]` |

### Constraints

| Class | Purpose |
|-------|---------|
| `ConstraintSpec` | Base class for constraint specification. |
| `ValueRange` | Value range constraint: `ValueRange(min_val, max_val)`. |
| `SizeConstraint` | Size constraint: `SizeConstraint(size)`. |
| `ConstrainedIntegerType` | INTEGER with fixed length (based on `ConstraintSpec`). |
| `ConstrainedOctetString` | OCTET STRING with fixed length. |
| `ConstrainedBitStringType` | BIT STRING with fixed length. |
| `ConstrainedSequenceOfType` | SEQUENCE OF with fixed element count. |

## Usage

### Creating INTEGER Subclasses with Named Values

```python
from COSEMpdu.x680 import IntegerType

class AccessResult(IntegerType):
    SUCCESS: int = 0
    HARDWARE_FAULT: int = 1
    READ_WRITE_DENIED: int = 3

# Creating a value
result = AccessResult(0)
print(str(result))  # "SUCCESS"
print(int(result))  # 0
```

### Creating BIT STRING Subclasses

```python
from COSEMpdu.x680 import BitStringType
from typing import Final

class Status(BitStringType):
    read: Final[int] = 0
    write: Final[int] = 1
    execute: Final[int] = 2

# Creating a bit string
status = Status((1, 0, 1))  # read, execute
print(str(status))  # "{read, execute}"
print(status.has_bit(1))  # False (write)
print(status.to_bin())  # "101"
```

### Creating SEQUENCE

```python
from dataclasses import dataclass
from COSEMpdu.x680 import SequenceType

@dataclass
class MySequence(SequenceType):
    id: IntegerType
    name: OctetStringType
```

### Creating ENUMERATED

```python
from COSEMpdu.x680 import EnumeratedType
from typing import Final

class DataAccessResult(EnumeratedType):
    SUCCESS: Final[int] = 0
    HARDWARE_FAULT: Final[int] = 1
    TEMPORARY_FAILURE: Final[int] = 2

result = DataAccessResult(0)
print(repr(result))  # "DataAccessResult.SUCCESS"
```

### Using Tags

```python
from COSEMpdu.x680 import Tag, Class

# Universal tag for INTEGER
universal_int = Tag(2, Class.UNIVERSAL)

# Context-specific tag
context_tag = Tag(0, Class.CONTEXT_SPECIFIC)

# Application tag
app_tag = Tag.application(31)
```
