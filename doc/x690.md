# X.690 — BER/X.690 TLV Encoding

## Overview

The `x690` module implements basic BER (Basic Encoding Rules) TLV encoding according to the X.690 standard (ISO/IEC 8825-1). It provides low-level functions for encoding/decoding tags, length, and content — the three components of a TLV structure.

The module is used as a foundation for:
- **BER codec** (`ber.py`) — complete `get`/`put` implementations for all ASN.1 types
- **A-XDR codec** (`axdr.py`) — partially uses BER format for explicit tags
- **ACSE APDU** (`acse.py`) — encoding ACSE messages in BER

## Module Contents

### `Tag` Class

| Attribute/Method | Description |
|------------------|-------------|
| `class_number: int` | Tag number (non-negative integer) |
| `class_: Class` | Tag class: `UNIVERSAL`, `APPLICATION`, `CONTEXT_SPECIFIC`, `PRIVATE` |
| `constructed: bool` | Constructed encoding flag |
| `is_universal()` | Check for UNIVERSAL class |
| `is_application()` | Check for APPLICATION class |
| `is_context_specific()` | Check for CONTEXT-SPECIFIC class |
| `is_private()` | Check for PRIVATE class |
| `universal(number)` | Create a UNIVERSAL tag |
| `application(number)` | Create an APPLICATION tag |
| `context(number)` | Create a CONTEXT-SPECIFIC tag |
| `private(number)` | Create a PRIVATE tag |

### Encoding/Decoding Functions

Encoding and decoding are done via class methods on `Tag` and `Length`, plus a standalone `put_length` helper:

| Function / Method | Description |
|-------------------|-------------|
| `Tag.get(buf)` | Decode a tag from the buffer |
| `Tag.put(buf)` | Encode this tag to the buffer |
| `Length.get(buf)` | Decode length from the buffer |
| `put_length(buf, value)` | Write length value to the buffer (BER format: short/long form) |

### Helper Types

| Class | Description |
|-------|-------------|
| `ReadableByteBuffer` | Buffer with sequential read support |
| `ValueOrError` | Operation result: value or error |

## Usage

### TLV Encoding

```python
from COSEMpdu.x690 import Tag, Length
from COSEMpdu.x680 import Class
from COSEMpdu.byte_buffer import ByteBuffer

# Create a tag
tag = Tag(0, Class.APPLICATION, constructed=True)

# Encode TLV: tag + length + content
buf = ByteBuffer()
content = b'\x01\x02\x03'
tag.put(buf)
Length(len(content)).put(buf)
buf.write(content)

# Decode TLV: tag + length + content
buf.set_pos(0)
read_tag = Tag.get(buf)
read_length = Length.get(buf)
read_content = buf.read(read_length.value)
```

### Length Encoding

```python
from COSEMpdu.x690 import put_length, Length
from COSEMpdu.byte_buffer import ByteBuffer

buf = ByteBuffer()
put_length(buf, 200)   # short form (1 byte)
put_length(buf, 1000)  # long form (2+ bytes)

buf.set_pos(0)
length = Length.get(buf)  # -> Length(200)
length = Length.get(buf)  # -> Length(1000)
```
